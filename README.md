# Tech-Shop

[English versoin](#english-version-of-project)


##  О проекте
Этот проект был создан для закрепления моих навыков в разработке веб-приложений.  
Он представляет собой интернет-магазин техники с базовым функционалом.

---

##  Функционал

На данный момент в проекте реализовано:

- Каталог товаров (телефоны, ноутбуки, наушники, зарядные устройства)
- Добавление товаров через файл `script.js`
- Отображение общей суммы при оформлении заказа
- Уникальный дизайн в космическом стиле 

---

## Как добавить новый товар

Чтобы добавить товар в каталог:

1. Откройте файл `script.js`
2. Найдите константу `products`
3. Добавьте новый объект по существующему шаблону

---

## Работа файлом и папок

### English version of project 

##  About the Project
This project was created to help me solidify my skills in web application development.  
It is an online electronics store with basic functionality.

---

##  Features

Currently, the project includes:

- Product catalog (phones, laptops, headphones, chargers)
- Adding products via the `script.js` file
- Displaying the total amount during checkout
- Unique space-themed design 

---

## How to add a new product

To add a product to the catalog:

1. Open the `products.js` file
2. Find the `products` constant
3. Add a new object using the existing template

---

## Working with files and folders

All logic is written in `script.js`
The working HTML file is index.html
All styles are in style.css

In the folders 

image, ImageA, ImageH, ImageL, ImageS, ImageX, one file contains only Apple products, another only Samsung, and so on
